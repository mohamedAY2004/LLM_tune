Cheat sheet

Evaluate and ship

Score honestly, find where the model breaks, then merge, push and document it. Taught in Lesson 8 and Lesson 9, and used in the capstone.

Score one row (the core of score())

inputs = tok.apply_chat_template(row["prompt"], add_generation_prompt=True,
             return_tensors="pt", return_dict=True).to(model.device)
with torch.no_grad():
    out = model.generate(**inputs, max_new_tokens=40,
                         do_sample=False)            # greedy: reproducible
reply = tok.decode(out[0, inputs["input_ids"].shape[1]:],
                   skip_special_tokens=True).strip()
try:
    pred = json.loads(reply); valid += 1             # format
except json.JSONDecodeError:
    pred = {}
gold = json.loads(row["completion"][0]["content"])
right += sum(pred.get(k) == v for k, v in gold.items())   # content

Raise max_new_tokens when the JSON gets longer (the capstone uses 60).

Metrics

MetricDefinitionMeasures
valid-JSON ratereplies that json.loads accepts ÷ rowsformat
field accuracyexactly matching field values ÷ (rows × fields)content

Report both. Format can pass while content fails, but not the reverse: a reply that doesn’t parse scores zero fields. A field the message lacks should be null, and pred.get(k) == None also counts an omitted key as right.

An honest before/after table

  • Score the base model first. Training changes the model in place.
  • Use the same rows for both models. Different rows differ in difficulty (the base model scored 0.575 on one set and 0.025 on another).
  • Report held-out rows: unseen names, values and phrasings. A training-row score only shows the model learned its data.
  • Use greedy decoding (do_sample=False).
  • Small test sets are coarse: with 40 rows, one row is 2.5 points.

Stress-test checklist

Write (message, expected_json) pairs that break the training pattern, then run them greedily:

  • a field left out entirely → expect null
  • another number in the sentence (“has 3 kids”, “in 2019”)
  • two-word names and cities (“Hana Tanaka”, “Rio de Janeiro”)
  • typos, lowercase, no punctuation
  • another language, or chit-chat around the facts
  • values that need reasoning (“born in 1990”, “mid-thirties”)
  • two people in one message, and an instruction hidden in the text

Only report failures you actually ran. In Lesson 8, the age in words and the French sentence both passed.

Merge, save, reload, re-score

from peft import PeftModel
base = AutoModelForCausalLM.from_pretrained(model_id, dtype=torch.float32)
merged = PeftModel.from_pretrained(base, adapter_dir).merge_and_unload()

merged.save_pretrained(out_dir)
tok.save_pretrained(out_dir)          # the chat template lives here
shipped = AutoModelForCausalLM.from_pretrained(out_dir, dtype=torch.float32)
assert score(shipped, tok, test_rows) == lora_scores

merge_and_unload() returns a plain Transformers model. It also modifies the wrapped base model, so save the adapter first if you still need it.

Push to the Hub

  1. Create a token with the Write role at huggingface.co/settings/tokens.
  2. Colab: key icon → secret HF_TOKEN → turn on notebook access. Elsewhere: huggingface_hub.login().
from huggingface_hub import get_token, whoami
assert get_token(), "no token found"
repo_id = f"{whoami()['name']}/my-extractor"

shipped.push_to_hub(repo_id)   # creates the repo if needed
tok.push_to_hub(repo_id)
card.push_to_hub(repo_id)      # last: a model push into an
                               # empty repo writes its own README

push_to_hub(repo_id, private=True) makes a new repo private. ModelCard.push_to_hub can’t create a repo.

Load it back

# merged model: three lines, plain Transformers
from transformers import pipeline
extractor = pipeline("text-generation", model=repo_id)

Model card template

from huggingface_hub import ModelCard
card = ModelCard(f"""---
base_model: {model_id}
library_name: transformers
license: apache-2.0
pipeline_tag: text-generation
tags: [json, information-extraction, sft]
---

# {repo_id}

What it does, in one sentence. A three-line usage example.

## Training data
What, how many rows, how it was made.

## Evaluation
| model | valid-JSON rate | field accuracy |
|---|---|---|
| base | {before['valid_json']:.2f} | {before['field_accuracy']:.2f} |
| this model | {after['valid_json']:.2f} | {after['field_accuracy']:.2f} |

## Intended use
## Limitations
Your failure tags, in plain words.
""")
card.save(f"{out_dir}/README.md")

Keep the --- block unindented at the very top, or the metadata is silently dropped. base_model links your model to its parent on the Hub.
