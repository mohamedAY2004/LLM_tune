Cheat sheet

Dataset to fine-tuned model

Chat data for TRL, one SFTTrainer run, and a before/after score. Taught in Lesson 4 and Lesson 5.

Two chat shapes

# messages: loss on the WHOLE sequence by default
{"messages": [{"role": "user", "content": "..."},
              {"role": "assistant", "content": "..."}]}

# prompt-completion: loss on the COMPLETION only by default
{"prompt":     [{"role": "user", "content": "..."}],
 "completion": [{"role": "assistant", "content": "..."}]}

Both render to the same text. Prompt-completion gives you the -100 prompt mask for free (completion_only_loss=None means “auto”). This course uses it.

Rows to a Dataset

from datasets import Dataset

train = Dataset.from_list(make_rows(500, "train", seed=0))
test  = Dataset.from_list(make_rows(40, "test", seed=1))

train[0]              # one row: a dict
train["completion"]   # one column
train[:2]             # dict of lists

The test split uses unseen names, cities and phrasings, so it measures generalisation. A random slice of the training data wouldn’t.

See the training text

chat = row["prompt"] + row["completion"]
text = tok.apply_chat_template(chat, tokenize=False)

# The prompt alone, as at inference:
p = tok.apply_chat_template(row["prompt"], tokenize=False,
                            add_generation_prompt=True)
text[len(p):]   # the completion: what the loss counts
# '{"name": "Kenji", ...}<|im_end|>\n'

Leave add_generation_prompt off for training text: the reply is already there.

Measure lengths with map

def add_length(row):
    ids = tok.apply_chat_template(
        row["prompt"] + row["completion"],
        return_dict=True)["input_ids"]
    return {"n_tokens": len(ids)}

train = train.map(add_length)   # returns a NEW dataset
max(train["n_tokens"])          # 91 for our task

Pick max_length above the longest row. Truncation keeps the start, so a short cap cuts the answer and its <|im_end|>.

SFTConfig, T4-safe

from trl import SFTConfig, SFTTrainer

args = SFTConfig(
    output_dir="sft-smollm2-135m",
    num_train_epochs=1,             # default 3
    per_device_train_batch_size=8,  # Keras batch_size
    learning_rate=5e-5,             # default 2e-5
    max_length=256,                 # default 1024
    bf16=False,                     # default True; T4 has no bf16
    logging_steps=10,
    save_strategy="no",
    report_to="none",
)

Other SFTConfig defaults that differ from TrainingArguments: gradient_checkpointing=True, logging_steps=10.

Train and read the log

trainer = SFTTrainer(model=model, args=args,
                     train_dataset=train,
                     processing_class=tok)
trainer.train()

for log in trainer.state.log_history:
    if "loss" in log:
        print(log["step"], log["loss"],
              log["mean_token_accuracy"])

loss and mean_token_accuracy are computed on unmasked training tokens. They show fit, not generalisation. Colab’s progress table shows only the loss.

Check the mask

ex = trainer.train_dataset[0]   # keys: prompt, completion,
                                #       input_ids, labels
counted = [i for i, l in zip(ex["input_ids"], ex["labels"])
           if l != -100]
tok.decode(counted)   # only the completion

Prompt-completion rows get labels with every prompt position set to -100. Here 23 of 84 tokens count.

Gotchas (TRL 1.15, Transformers v5)

Old codeNow
SFTConfig(max_seq_length=...)max_length=.... The old name raises TypeError.
SFTTrainer(tokenizer=tok)processing_class=tok. The old name raises TypeError.
SFTTrainer(model="id")Loads float32, unlike from_pretrained’s checkpoint dtype. Set model_init_kwargs={"dtype": ...} to change it.
Default bf16True in SFTConfig. Pass bf16=False on a T4.
