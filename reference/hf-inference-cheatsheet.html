Cheat sheet

Load, template, generate

Running a Hugging Face chat model, from checkpoint id to decoded reply. Taught in Lesson 1.

Load a matched pair

import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_id = "HuggingFaceTB/SmolLM2-135M-Instruct"
device = "cuda" if torch.cuda.is_available() else "cpu"

tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, dtype=torch.float32).to(device)   # already in eval mode

Always load both from the same id. The course loads small models in torch.float32 because it runs anywhere. If you leave dtype out, v5 uses "auto", the checkpoint’s saved precision (often bf16, which a T4 lacks natively). Older code calls this argument torch_dtype.

Chat template

messages = [
  {"role": "system", "content": "..."},     # optional
  {"role": "user", "content": "..."},
]
# As text, to inspect:
text = tok.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True)

# As tensors, for the model:
inputs = tok.apply_chat_template(
    messages, add_generation_prompt=True,
    return_tensors="pt", return_dict=True).to(device)

add_generation_prompt=True appends the opening of the assistant turn. Use it at inference time.

Inspect tokens

ids = inputs["input_ids"]             # (batch, seq)
tok.convert_ids_to_tokens(ids[0])     # ['<|im_start|>', 'system', 'Ċ', ...]
tok.decode(ids[0])                    # back to text
tok.eos_token, tok.eos_token_id       # '<|im_end|>', 2  (SmolLM2)
len(tok)                              # vocab size

Ġ marks a leading space and Ċ a newline (byte-level BPE).

One forward pass

with torch.no_grad():                 # no autograd bookkeeping
    logits = model(**inputs).logits   # (batch, seq, vocab)

next_id = logits[0, -1].argmax().item()   # greedy next token
tok.decode([next_id])

Position t scores every token as the token at position t+1, so it’s a classifier at every position.

Generate & decode

with torch.no_grad():
    out = model.generate(**inputs, max_new_tokens=128,
                         do_sample=False)   # greedy
# out = prompt ids + new ids  ->  slice off the prompt
new_ids = out[0, inputs["input_ids"].shape[1]:]
reply = tok.decode(new_ids, skip_special_tokens=True)

Sampling: do_sample=True, temperature=0.7, top_p=0.9. Generation stops at the EOS token or at max_new_tokens.

Shapes to remember

TensorShape
input_ids, attention_mask(batch, seq)
logits(batch, seq, vocab)
generate() output(batch, seq + new)

Transformers v5 notes

  • apply_chat_template(..., return_tensors="pt") returns a BatchEncoding dict by default. Pass return_dict=True anyway so the code also works on v4.
  • dtype= replaces torch_dtype=.
