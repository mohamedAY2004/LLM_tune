Reference

Further reading

Trusted sources behind each lesson, and the communities to ask when you’re stuck. Versions used in this course: Transformers 5.19, TRL 1.15, PEFT 0.21, Datasets 5.1, PyTorch 2.14.

Watch for stale tutorials

Many tutorials predate Transformers v5. If you see load_in_4bit=True in from_pretrained, torch_dtype, tokenizer= in a Trainer, max_seq_length in TRL, or TensorFlow model classes, translate them with the v5 migration guide.

PyTorch, coming from Keras

  • PyTorch: Learn the BasicsThe official 8-page path: tensors, Dataset/DataLoader, nn.Module, autograd, the training loop, save/load. The PyTorch underneath every Hugging Face call.
  • PyTorch: Optimizing Model ParametersThe explicit loop that model.fit() hides: forward → loss.backward() → optimizer.step() → zero_grad(). Lesson 2.
  • Keras 3: Writing a training loop from scratch in PyTorch (fchollet)The best Keras → PyTorch bridge. Note that torch losses take (pred, target), the reverse of Keras.
  • What is torch.nn really? (Jeremy Howard)Builds a training loop from raw tensors up to nn.Module, optim and DataLoader. Read it when Trainer feels like magic.
  • PyTorch: CrossEntropyLossThe ignore_index=-100 behind every loss mask. Lesson 3.
  • HF LLM Course 7.6: Training a causal language modelShows that the label shift happens inside the model, so you pass labels=input_ids unshifted. Lesson 2.

Primary explainers

  • LoRA paper (Hu et al., 2021)What r, lora_alpha and target modules mean (§4). Read after your first LoRA run.
  • QLoRA paper (Dettmers et al., 2023)NF4, double quantization, paged optimizers: why 4-bit training fits on small GPUs.
  • LoRA Without Regret (Thinking Machines, 2025)Modern LoRA hyperparameters: all-linear targets, learning rate about 10× full fine-tuning.
  • HF blog: Chat templates, the silent performance killerWhy a wrong prompt format quietly degrades a model. Concepts only; take the code from the docs.
  • Raschka: LLMs from Scratch (ch. 7 instruction fine-tuning, appendix E LoRA)SFT and LoRA written by hand in plain PyTorch. Interview-depth understanding of what SFTTrainer does.
  • Karpathy: Neural Networks: Zero to HeroDeep intuition for causal LMs and tokenizers, including why labels are the inputs shifted by one. Optional long-form viewing.

Models, data, compute

  • Models (Apache-2.0, not gated): SmolLM2-135M-Instruct (full fine-tuning), SmolLM2-360M-Instruct and Qwen2.5-0.5B-Instruct (LoRA), SmolLM2-1.7B-Instruct (QLoRA).Avoid Qwen3/SmolLM3 for short-answer SFT demos: their “thinking” mode is on by default.
  • Warm-up data: HuggingFaceTB/smoltalk, config everyday-conversationsA messages column, 2,260 rows: a tiny SFT practice set.
  • Capstone stretch data: gretelai/gretel-pii-masking-en-v1Apache-2.0, not gated, 50k/5k/5k synthetic documents with labelled personal-information spans. A real-data version of the extractor, once the synthetic one passes.
  • Colab FAQFree sessions last 12 hours at most. The GPU type isn’t published (a T4 in practice).
  • Kaggle Notebooks1× P100 or 2× T4, about 30 GPU-hours a week. Pick the T4 for QLoRA.

The timings quoted in the lessons were measured on a 4 GB laptop GPU (RTX 3050 Ti). A Colab or Kaggle T4 will differ, usually for the better.
