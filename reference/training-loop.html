Training loop & labels

One PyTorch training step for a causal LM, and the labels that decide what it learns. Taught in Lesson 2 and Lesson 3.

The loop

optimizer = torch.optim.AdamW(model.parameters(), lr=5e-5)

model.train()                        # training mode
for step in range(num_steps):
    out = model(**batch, labels=labels)
    out.loss.backward()              # gradients -> p.grad
    optimizer.step()                 # update the weights
    optimizer.zero_grad()            # clear p.grad

model.eval()                         # before generating

Create the optimizer once, before the loop. AdamW keeps running averages for every parameter.

Causal-LM labels

batch = tok.apply_chat_template(
    messages_with_answer,             # user + assistant turns
    return_tensors="pt", return_dict=True).to(device)

out = model(**batch, labels=batch["input_ids"])
out.loss                              # mean cross-entropy

# the same number, by hand (the model shifts internally):
F.cross_entropy(out.logits[0, :-1], batch["input_ids"][0, 1:])

Don’t shift the labels yourself. Position t is scored against token t+1 inside the model. No labels → out.loss is None.

Mask the prompt (loss on the answer only)

full = tok.apply_chat_template(
    row["prompt"] + row["completion"],
    return_tensors="pt", return_dict=True)
prompt_len = tok.apply_chat_template(
    row["prompt"], add_generation_prompt=True,
    return_tensors="pt", return_dict=True)["input_ids"].shape[1]

labels = full["input_ids"].clone()    # copy!
labels[:, :prompt_len] = -100         # ignored by the loss
loss = model(**full, labels=labels).loss

-100 is cross-entropy’s default ignore_index. Pad positions get -100 too; data collators do it. TRL’s SFTTrainer builds these same labels for prompt-completion data.

Modes and gradients

CallWhat it does
model.train()Dropout etc. on. Use before training.
model.eval()Dropout etc. off. from_pretrained returns this mode. Does not stop gradients.
with torch.no_grad():No gradient tracking, less memory. Use for generation and evaluation.
model.trainingTrue in train mode. Handy to check.
